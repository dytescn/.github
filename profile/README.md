# dytescn

**dytes** 是一个 AI 设计插件包管理工具。

统一安装、更新与发布设计插件、设计软件、Web 能力库、系统库与模型包。

[官网](https://www.dytes.cn) · [dytes 仓库](https://github.com/dytescn/dytes) · [文档](https://github.com/dytescn/dytes/tree/main/docs) · [下载](https://github.com/dytescn/dytes/releases/latest)

## 核心项目

| 项目 | 说明 |
| --- | --- |
| [dytes](https://github.com/dytescn/dytes) | 安装、更新、发布与清单管理 |
| [designplugin_lib](https://github.com/dytescn/designplugin_lib) | 设计插件能力库 |
| [material_lib](https://github.com/dytescn/material_lib) | 设计素材与内容检索 |
| [workspace_lib](https://github.com/dytescn/workspace_lib) | 工作区与项目数据 |

## 安装

```bash
curl -fsSL https://www.dytes.cn/install.sh | sh
```

Windows PowerShell：

```powershell
irm https://www.dytes.cn/install.ps1 | iex
```
